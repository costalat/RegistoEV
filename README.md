# Registo EV

Gestão de mobilidade elétrica com Room, Compose, estatísticas avançadas e relatórios PDF oficiais.

**Versão Atual: 1.4**

### Principais Funcionalidades:
- Registo de movimentos e quilometragem.
- Gestão de carregamentos (Portátil, MOBI.E, Exército).
- Dashboard interativo com estatísticas semanais, mensais e anuais (ISO 8601).
- Exportação de Reporte Mensal em PDF (Layout Oficial).
- Backup e Restauro de dados em JSON.
- Design Premium "Deep Dark" otimizado.

---
Desenvolvido com foco na precisão de dados e facilidade de reporte.
